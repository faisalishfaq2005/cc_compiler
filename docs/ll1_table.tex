\section{Introduction}
% ------------------------------------------------------------------

The LL(1) parse table $M[A, a]$ specifies, for each non-terminal $A$ on top
of the parse stack and each possible lookahead terminal $a$, the production
that must be applied.

\subsection{Construction Rule}

For each production $A \to \alpha$:
\begin{enumerate}
  \item For each terminal $t \in \text{FIRST}(\alpha) \setminus \{\varepsilon\}$:
        set $M[A, t] = (A \to \alpha)$.
  \item If $\varepsilon \in \text{FIRST}(\alpha)$: for each $t \in \text{FOLLOW}(A)$:
        set $M[A, t] = (A \to \alpha)$.
\end{enumerate}

\subsection{The Parsing Algorithm}

\begin{lstlisting}[style=pseudo]
push $ then push Start onto the stack
token = next_token()
loop:
  X = top of stack
  if X == $ and token == $: ACCEPT
  elif X is a terminal:
    if X == token: pop; token = next_token()
    else: error("unexpected token")
  else:  // X is a non-terminal
    if M[X, token] is defined:
      pop X; push M[X, token] reversed
    else:
      error(); panic_mode_recover(FOLLOW(X))
\end{lstlisting}
